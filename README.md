# Awesome Claude Fable

A curated list of **Anthropic Claude Fable** (Fable 5 / Fable 5.1) resources: official docs, orchestration skills, plugins, and demos.

Original blurbs. This is **not** the F# [Fable compiler](https://github.com/fable-compiler/Fable) list. For that ecosystem see [kunjee17/awesome-fable](https://github.com/kunjee17/awesome-fable). Another Claude-focused catalog: [Anil-matcha/awesome-claude-fable-5](https://github.com/Anil-matcha/awesome-claude-fable-5).

PRs welcome. No leaked system prompts. No star-farming.
